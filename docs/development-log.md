## Основной функционал

Сводка по текущей реализации (версия 0.7.0). Результаты конкретных запусков и ограничения указаны в записях задач ниже.

- Монтаж по JSON-шаблонам: слои, холст, обрезка исходника, история undo/redo, локальная библиотека, сохранение проектов и черновиков.
- Проекты `.acup`: Save/Save As, открытие `.acup`/legacy JSON, импорт отдельной копии, перетаскивание, защита несохранённых правок и экспорт с соседней папкой медиа/шрифтов по относительным ссылкам.
- Многодорожечный таймлайн: независимые видео/аудиосегменты, split/trim/detach, Mute/Solo/Hide/Lock, gain/fades/waveform, Snap/Zoom; композитинг и микшер FFmpeg, оценка размера по общей длине.
- Предпросмотр Canvas и контрольный кадр FFmpeg; очередь экспорта со снимками параметров, прогрессом и отменой.
- Текстовые слои: локальные шрифты, заливка, обводка, тень, плашка, поворот и анимации появления/исчезновения. Canvas и экспорт через libass могут отличаться растеризацией текста.
- Удаление фона: chromakey/colorkey с despill и сохранением исходной прозрачности; локальная AI-обработка статичных изображений в прозрачный PNG с восстановлением оригинала. AI-обработка видео не реализована.
- BCC-style Chroma Key Studio: WebGL2 matte cleanup, Final/Matte/Source, пипетка 3×3, weighted primary key, choke/softness/levels/gamma, despill и Light Wrap; соответствующий многоступенчатый граф FFmpeg.
- BCC доступен для основного клипа и отдельных видеоотрезков: наследование, индивидуальные настройки, сохранение исходного цвета внутри объекта и коррекция рефлексов только по краям по умолчанию.
- Интеграции Google Drive и TikTok через OAuth. Реальный вход и публикация требуют реквизитов приложений и отдельной проверки с аккаунтом; сервисные тесты с контролируемыми ответами этого не подтверждают.
- Windows installer и portable EXE с FFmpeg/FFprobe и локальными AI-ресурсами. Упаковка проверяется отдельным сценарием.

## 2026-11-02 — BCC: сохранение оттенка/яркости и основной клип, 0.6.1

- Запрос: устранить затемнение/неверный оттенок при включении BCC и разрешить эффект на основном клипе.
- Причины в прежней реализации: despill корректировал весь RGB-слой, в том числе непрозрачный центр и естественные тёплые цвета; additive luma correction с последующим clipping могла терять яркость. Light Wrap использовал alpha*(1-blurredAlpha) и мог окрашивать равномерно полупрозрачную область целиком. Сам основной клип проходил отдельную ветку без BCC и без панели настроек.
- Цвет: добавлен edges_only (по умолчанию true); краевая маска ограничивает despill контуром. При Balance=0.5 порогом служит максимум двух остальных каналов, что сохраняет жёлтые/тёплые оттенки без зелёного избытка. Восстановление Y выполняется внутри RGB gamut смешиванием с белым, без отсечения пересвеченных каналов. Нейтральные и красные ключи не запускают green/blue despill. WebGL2, CPU reference и FFmpeg RGB geq используют согласованную формулу.
- Light Wrap: маска заменена на положительную пространственную разницу alpha-blurredAlpha; равномерная полупрозрачность не подсвечивается целиком. Для новых настроек Light Wrap выключен по умолчанию; прежнее явное enabled=true сохраняется, его можно выключить для исходного цвета. Это намеренная коррекция оттенка, а не обязательная часть удаления фона.
- Основной клип: main_clip_layout.background_removal задаёт общий BCC; timeline video clip.background_removal переопределяет его для выбранного сегмента, включая enabled=false. Панель основного клипа работает с выбором из списка слоёв, панель сегмента — с таймлайном; есть возврат к наследованию. Split сохраняет независимость конфигов, undo/redo, сохранение/restore и пипетка поддерживают оба уровня. Detach не копирует видеоэффект на аудио.
