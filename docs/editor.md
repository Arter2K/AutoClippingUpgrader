# Шаг 3 — монтажный редактор

Все три этапа соединены в Electron-приложение. Слева — шаблоны и слои, в центре — интерактивный Canvas 2D и таймлайн, справа — экспорт и публикация. Тёмная тема использует Tailwind, shadcn-style компоненты на Radix Slot/CVA, Lucide и Framer Motion. Данные редактора и истории правок хранятся в Zustand.

## Запуск

В текущей папке зависимости установлены, приложение собрано. Можно открыть `Start.cmd` двойным щелчком. Либо из PowerShell:

```powershell
.\scripts\run.ps1 preview
```

Разработка с Vite: `.\scripts\run.ps1 dev`. После изменения исходников пересборка: `.\scripts\run.ps1 build`. Для свежей копии проекта сначала установите зависимости (`npm install` или pnpm 11). Нужны Node.js >=22.12 и FFmpeg/FFprobe >=7. Скрипт использует локальную проверочную сборку из `.tools`, когда она присутствует, либо переменные FFMPEG_PATH/FFPROBE_PATH/PATH. Он также умеет находить Node из bundled runtime этого окружения, если Node отсутствует в обычном PATH.

Также подготовлены самостоятельные Windows EXE — установщик и portable, уже со встроенными FFmpeg/FFprobe. См. [windows-build.md](windows-build.md). `Start.cmd` остаётся способом запуска из папки исходников.

## Основной сценарий

1. Нажмите «Импорт медиа» или перетащите видео в центральную область. MP4, MOV, MKV, WebM и AVI проверяются FFprobe; для таймлайна FFmpeg создаёт шесть настоящих кадров. Исходный файл не переносится и не изменяется.
2. Выберите шаблон слева. Есть три встроенных композиции: Clean Vertical с размытым фоном, Focus с заполнением холста и Gaming с квадратной областью. Кнопка «+» создаёт новый шаблон; сохранение добавляет его в локальную библиотеку.
3. Выберите основной клип или overlay. Справа во вкладке «Слой» доступны X/Y, Width/Height, режим масштабирования, кроп и фон. Объект можно перетаскивать на холсте; нижний правый маркер меняет размер. Для текста маркер изменяет `scale`.
4. Добавьте текст, изображение или видео. Доступны PNG/JPEG/GIF/WebP, видеослои и шрифты TTF/OTF. Редактируются текст, размер/цвет/обводка/тень, anchor, scale, opacity, Z-index, интервалы и fades. Файлы можно заменять. Есть дублирование, удаление, блокировка, скрытие и изменение порядка слоёв.
5. Редактируйте сегменты в многодорожечном таймлайне: перемещайте их, разрезайте кнопкой Split (S), обрезайте ручками по краям, отделяйте звук и меняйте громкость. Щелчок по линейке перемещает playhead. Воспроизведение повторяет весь таймлайн; кнопка звука влияет только на предпросмотр. Числовые In/Out доступны, пока основной клип не разрезан. Подробности: [multitrack-timeline.md](multitrack-timeline.md).
6. Настройте экспорт. Estimated File Size пересчитывается от конца последнего активного сегмента и целевого битрейта. Для CBR/VBR используется требуемая формула с делителем 8192; для CRF/CQP показано, что размер зависит от содержимого.
7. Нажмите «Экспортировать клип» и выберите новый MP4-файл. Кнопка остаётся в постоянном нижнем блоке инспектора. Уже существующее видео не перезаписывается.
8. В очереди видны прогресс, скорость, проходы и результат. После успешного рендера доступно открытие папки; готовый MP4 автоматически подставляется во вкладку публикации. Отправка в TikTok требует отдельного действия.

Для старых шаблонов без многодорожечной модели, если выбранные интервалы слоёв не помещаются в trim, инспектор предложит «Подогнать тайминги». Это явная операция с поддержкой undo; скрытые слои в финальный граф не попадают.

## Холст и точный кадр

1080×1920 и 1440×2560 доступны в списке над холстом. Диалог собственного размера принимает чётные размеры до 8192×8192. При смене размера масштабируются координаты элементов и размер шрифта; исходный crop остаётся в пикселях исходника. Codec level сбрасывается в auto.

Canvas отрисовывает основной клип, размытую подложку, текст с выбранным локальным шрифтом, alpha, медиа-слои, fades и хромакей. Сетка содержит thirds и направляющие безопасной области; snapping привязывает объект к краям, центру и шагу 10 px. Zoom изменяет только отображение, не координаты проекта. Заблокированные слои доступны через список, но не перетаскиваются.

Интерактивный предпросмотр рассчитан на скорость. Браузерный blur, метрики многострочного текста, GIF/WebP-анимация и края chromakey могут отличаться от FFmpeg. Нажмите «FFmpeg-кадр», чтобы получить PNG тем же filter_complex, который используется при экспорте. В режиме reference редактирование холста выключено; крестик возвращает интерактивный вид, изменение playhead или проекта сбрасывает старый кадр. Проверку можно отменить.

Некоторые входные кодеки (например, HEVC в отдельных системах) могут не декодироваться Chromium. В этом случае интерфейс показывает сообщение, а точный FFmpeg-кадр и экспорт остаются доступны. Это не означает, что все кодеки FFmpeg поддерживаются браузерным видеоэлементом.

## Параметры экспорта

- H.264/H.265 через NVIDIA NVENC или libx264/libx265; fallback на CPU включается отдельным переключателем.
- CBR, VBR 1-pass/2-pass, CRF/CQ и CQP, target/max bitrate, buffer, quality.
- 30/60/120 fps, profile/level, preset NVENC p1–p7 или software preset, GOP, yuv420p.
- AAC 192/256/320 kbps, 48 kHz, однопроходная loudnorm. Если нет активных аудиосегментов, лишний поток не создаётся.

Снимок каждого задания содержит шаблон и trim на момент запуска. Последующие правки не меняют уже поставленное задание. Задания исполняются по одному, очередь ограничена двенадцатью активными записями; отменить можно как ожидающее, так и текущее задание. Очередь находится в памяти и не продолжается после закрытия приложения.

Экспорт сначала сохраняется во временный файл, затем копируется в выбранное место. Исходник и существующие результаты защищены от перезаписи. При ошибке показывается диагностическое сообщение FFmpeg, успешный результат остаётся доступен через кнопку «Файл».

## Google Drive и TikTok

Во вкладке публикации подключаются аккаунты из шага 2. Подробности и `.env` — в [publishing.md](publishing.md).

Чтобы включить автозагрузку после рендера, подключите Drive, создайте или выберите папку и включите опцию в инспекторе экспорта. Настройка сохраняется в проекте. При включённой опции загрузка начинается только после успешного локального рендера. Если Drive недоступен, готовый MP4 остаётся на диске и его можно отправить повторно из вкладки публикации. Отмена после сохранения видео не удаляет локальный результат.

Действующие OAuth-реквизиты по-прежнему нужны для реального входа. Во время разработки облачные публикации и отправки в аккаунты не выполнялись.

## Проекты, JSON и сохранение

- Ctrl+S / иконка дискеты сохраняет проект `.acu.json`: шаблон, ссылку на исходник, trim и настройки после рендера. Ctrl+O открывает проект.
- Локальный черновик автоматически сохраняется после правок и восстанавливается при следующем запуске. При обычном закрытии окна передаётся последний снимок и ожидается запись (с ограниченным временем ожидания).
- Ctrl+Z / Ctrl+Shift+Z отменяют и повторяют правки шаблона и trim. Перетаскивание создаёт одну запись истории. Максимум — 50 прошлых снимков; пользовательские исходники история не копирует.
- Импорт/экспорт шаблонов работает с исходной JSON-схемой, включая `main_clip_layout.Position`. Кнопка `{}` открывает полноценный редактор JSON с проверкой перед применением.
- `enabled` и `locked` — необязательные расширения overlay. Старые JSON без них остаются совместимыми.
- Экспортируемые проекты и шаблоны ссылаются на локальные медиа/шрифты; assets не упаковываются в JSON. При переносе на другой компьютер перенесите файлы и исправьте ссылки либо выберите файлы заново.
- Если файл отсутствует, проект открывается с предупреждением, чтобы его можно было восстановить, а не терять всё описание композиции.

Данные редактора находятся в `app.getPath('userData')/editor`: `draft.json`, библиотека `templates/`, кэш кадров `cache/`. OAuth-токены хранятся отдельно и никогда не включаются в проект или Zustand-store.

## Клавиатура

| Клавиши | Действие |
| --- | --- |
| Space | Воспроизведение / пауза |
| ← / → | Перемещение на кадр |
| Shift + ← / → | На 0.1 секунды |
| I / O | Установить In / Out по playhead |
| G / M | Сетка / звук предпросмотра |
| Ctrl+I | Импорт исходника |
| Ctrl+O / Ctrl+S | Открыть / сохранить проект |
| Ctrl+Z / Ctrl+Shift+Z | Undo / redo |
| Delete | Удалить выбранный overlay |
| Escape | Закрыть диалог |

Модальные диалоги удерживают Tab-фокус. Редактирование текста не перехватывается монтажными shortcuts.

## Проверка реализации

```powershell
.\scripts\run.ps1 build
.\scripts\run.ps1 test
.\scripts\run.ps1 test:electron
.\scripts\run.ps1 test:editor
$env:TEST_NVENC = '1'
.\scripts\run.ps1 test:integration
```

Native editor-сценарий использует настоящие BrowserWindow, preload, Canvas, локальные медиа и FFmpeg. Диалоги выбора файлов в тесте направляются в собственную временную папку. Проверяются загрузка и range-перемотка, текст, координаты, drag, undo/redo, реакция оценки на trim/битрейт, настоящий FFmpeg-кадр, сохранение JSON и проекта, смена разрешения, экспорт MP4 и восстановление черновика. Хеш исходного видео после всего сценария сравнивается с исходным.

Артефакты проверки: `out/editor-qa/editor-empty.png`, `editor-loaded.png`, `ffmpeg-reference.png`, `editor-render.mp4`, `result.json`. Тест работает без отображения окна и удаляет собственные временные профили только после завершения Electron, чтобы не оставлять заблокированные Chromium-файлы.

В версии 0.4 добавлены расширенная типографика, плашки, поворот и motion presets, ключевые цвета с пипеткой и Despill, локальное AI-удаление фона. Полная схема и инструкции: [layer-effects.md](layer-effects.md). Проверка новых функций: `.\scripts\run.ps1 test:effects`.

Версия 0.6 добавляет BCC-style Chroma Key Studio для фото/видео: [руководство](bcc-chroma-key.md). Новое включение Chroma Key создаёт BCC-конфиг; старые настройки переводятся отдельной кнопкой. Диагностические режимы Alpha Matte и Source Only влияют только на быстрый preview; экспорт и FFmpeg-кадр показывают Final Composite.

В 0.6.1 BCC доступен также для «Основного клипа» во вкладке «Слой». Выбор в списке слоёв задаёт общий эффект; выбор сегмента на таймлайне — индивидуальный, с кнопкой возврата к наследованию. Despill по умолчанию ограничен краями, Light Wrap включается отдельно. Подробнее: [BCC, основной клип и сохранение цвета](bcc-chroma-key.md).
