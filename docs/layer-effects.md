# Эффекты слоёв · 0.4

Выберите слой слева или на холсте: справа откроется вкладка «Слой». Экспорт и публикация остаются отдельными вкладками.

## Текст

Инспектор поддерживает TTF/OTF и список системных шрифтов; размер, вес 100–900, курсив, верхний регистр, интервалы, многострочность и выравнивание. Заливка, обводка, тень и скруглённая плашка имеют отдельные настройки. Общая прозрачность умножается на прозрачность заливки/тени/плашки. Поворот — от −180° до +180°.

Анимации появления и исчезновения: none, fade, pop bounce, slide up/down. Длительность по умолчанию 0.25 с, автоматически ограничивается половиной интервала слоя. При наличии `animation` она заменяет legacy fade-параметры текста. Скрытый слой не рендерится.

Сложный текст экспортируется через ASS: шрифт копируется во временную папку, плашка рисуется векторным контуром, положение/масштаб/прозрачность вычисляются общей с Canvas функцией. Анимация разбивается на события вокруг входа и выхода; статичная середина хранится одним интервалом. Обычный текст старых шаблонов сохраняет путь `drawtext` с `textfile` и `expansion=none`. Вводимые пользователем ASS-теги экранируются и отображаются как текст.

Canvas и libass используют разные механизмы растеризации/подбора начертаний. Метрики и сглаживание могут различаться; ASS дополнительно хранит время с точностью до сотых секунды. Пиксельная идентичность live preview не гарантируется. Кнопка «FFmpeg-кадр» показывает результат того же графа, который применяется при экспорте.

## Удаление фона

Для фото и видео: Enable Chroma Key, зелёный/синий/чёрный пресеты, произвольный HEX, Similarity 0.01–1 (0.15), Blend 0–1 (0.05), Despill. Пипетка использует системный EyeDropper; «С холста» позволяет выбрать пиксель без него. На время выбора ключ выбранного слоя отключается, сетка и рамки скрываются; Esc отменяет выбор.

Зелёный/синий фон обрабатывается `chromakey`, нейтральный (включая чёрный) — RGB-фильтром `colorkey`: только цветность не отличает чёрный от белого. Despill выбирает зелёный или синий канал. Новая маска умножается на исходный альфа-канал, поэтому прозрачные участки PNG сохраняются. Canvas использует облегчённую пиксельную обработку; точные края проверяйте FFmpeg-кадром.

Для статичных изображений доступна «Удалить фон (AI)». Обработка выполняется в отдельном worker локальной CPU/WASM-моделью @imgly/background-removal 1.7.0. Показываются этапы и прогресс, доступна отмена с остановкой worker. Результат — прозрачный PNG в `assets/processed`, исходник сохраняется и доступен через «Вернуть оригинал». Подмена пути участвует в undo/redo. AI для видео не предусмотрен.

Загруженные вручную шрифты сохраняются в `assets/fonts`. После сохранения/открытия проекта новые assets создаются рядом с его `.acu.json`; для ещё не сохранённого проекта используется workspace в `userData/editor`. Уже существующие файлы при Save As автоматически не переносятся: проект содержит абсолютные ссылки на assets.

## Совместимость схемы

`Overlay` и `Template` выводятся из Zod-схемы `src/shared/template.ts`. Новые поля необязательны; старые `chroma_key`, `font_color`, `stroke_width`, `shadow_x/y` продолжают работать. `background_removal` имеет приоритет над `chroma_key`, в том числе при `enabled:false`. Структурированные `fill_color`, `stroke`, `shadow`, `background_box` имеют приоритет над соответствующими прежними полями.

`position.rotation` и `position.scale` поддерживаются у текста и медиа. Старый `scale` остаётся совместимым множителем. Современный объект `animation` содержит `in_preset`, `out_preset`, `duration_sec`; `background_removal` — union `chromakey` / `ai_matting` с `original_source_path` для AI.

## Подготовка и проверки

```powershell
.\scripts\run.ps1 prepare:ai
.\scripts\run.ps1 build
.\scripts\run.ps1 test
.\scripts\run.ps1 test:integration
.\scripts\run.ps1 test:effects
.\scripts\run.ps1 dist:win
.\scripts\run.ps1 test:package
```

`prepare:ai` скачивает официальный архив только при первом запуске без кэша. В рабочей сборке сеть для модели не используется. Исходные изображения не отправляются в облако. Лицензии библиотеки/модели/ONNX включаются в EXE; IMG.LY использует AGPL, см. `build/THIRD-PARTY-NOTICES.md`.

Новые проверки включают реальные FFmpeg-кадры с тремя ключевыми цветами, исходной прозрачностью, кириллицей, вращением, плашкой и каждым motion preset; native Electron проверяет пипетку, настоящее ONNX inference, запись PNG и восстановление оригинала.
