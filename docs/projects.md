# Проекты .acup

Начиная с 0.7.0 собственный формат проекта — **`.acup` (AutoClippingUpgrader Project)**. Это JSON-манифест с сигнатурой `AutoClippingUpgrader` и версией схемы `1`. Он хранит название, настройки холста и рендера, исходник, trim, все дорожки и сегменты, порядок, Mute/Solo/Volume, fades, текст, шрифты, BCC/AI-параметры и настройки публикации без токенов. Это формат этого редактора; совместимость с `.aep` и `.prproj` не реализована.

## Сохранение и открытие

- **Файл → Сохранить** / **Ctrl+S**: первый раз выбирается путь `.acup`, затем обновляется тот же файл. Исходные видео и аудио не изменяются. Запись манифеста атомарная через временный файл.
- **Сохранить как…** / **Ctrl+Shift+S**: создаётся проект по новому пути и дальнейшие сохранения идут туда. Предыдущий файл остаётся на диске.
- **Открыть проект…** / **Ctrl+O**: открывает `.acup` или старый JSON-проект `.acu.json`. Проект также можно перетащить на центральную область редактора. Старые проекты можно открыть через JSON-фильтр диалога.
- **Импорт проекта…**: загружает композицию как самостоятельный несохранённый проект. Следующий Ctrl+S предлагает новый путь, исходный проект не перезаписывается. Импорт заменяет текущую композицию, объединение двух таймлайнов не реализовано.
- Перед новым проектом, открытием, импортом или перетаскиванием изменённого проекта предлагаются **Сохранить / Не сохранять / Отмена**. Отмена выбора файла сохраняет текущую композицию.

Имя текущего файла видно в шапке, полный путь — в подсказке. Звёздочка означает изменения после сохранения. Undo/redo консервативно отмечает проект изменённым, даже если он вернулся к прежнему содержимому. Восстановленный черновик также отмечается изменённым.

Обычный `.acup` ссылается на медиа и шрифты. На одном диске ссылки сохраняются относительно папки проекта, между дисками — абсолютными. Перенос одного манифеста не переносит исходники. Если файл отсутствует, редактор показывает предупреждение; ссылка на недоступный основной исходник и его trim сохраняются при повторном сохранении. Автоматического поиска и массовой перепривязки недостающих медиа пока нет.

## Экспорт с медиа

**Файл → Экспорт проекта с медиа…** создаёт:

```text
Мой монтаж.acup
Мой монтаж.media-xxxxxxxx/
  <уникальное имя>-source.mp4
  <уникальное имя>-audio.wav
  <уникальное имя>-font.ttf
  …
```

Переносите **и `.acup`, и соседнюю папку `.media-…`**, сохраняя их относительное расположение. Откройте `.acup` на другом компьютере или импортируйте его отдельной копией. Имя папки уникально для каждого экспорта; повторный экспорт не удаляет медиа предыдущих копий.

Копируются все файлы, на которые ссылается проект: основное и дополнительное видео, аудио, изображения, шрифты, обработанный AI PNG и оригинал для «Вернуть оригинал», включая выключенные слои. Повторные ссылки копируются один раз, совпадающие имена из разных папок не конфликтуют. Экспорт требует доступности всех файлов. Итоговый манифест публикуется после успешного копирования; ошибка не заменяет существующий проект. Исходная композиция и путь текущего сохранения не меняются. Файлы потоково копируются с диска; это не ZIP и не один файл со встроенным видео.

## Черновик и ограничения

Локальный `userData/editor/draft.json` автоматически обновляется после правок и перед штатным закрытием окна, включая путь текущего `.acup`. Черновик восстанавливается при следующем запуске. Закрытие окна сохраняет локальный черновик, **но не обновляет `.acup` на диске**: для передачи актуальной версии используйте Ctrl+S или экспорт с медиа. Резервных версий проекта пока нет. Не закрывайте приложение во время экспорта медиа.

Диалоги и файловые операции выполняются в main через проверяемый IPC; renderer не получает файловую систему. Проект не содержит OAuth-секретов, токенов или копий AI-моделей. Макросов/скриптов формат не исполняет. Чтение ограничено манифестами до 32 MB; неизвестная версия и повреждённый JSON отклоняются, текущий монтаж сохраняется. Системная ассоциация расширения и открытие двойным щелчком пока не зарегистрированы — используйте меню или перетаскивание.

Проверка сценария: `$env:ACU_TEST_PROJECTS='1'; .\scripts\run.ps1 test:editor`. Она запускает настоящий Electron, проверяет Save/Save As, отмену, предупреждение о правках, экспорт/перенос/импорт медиа и шрифта, реальный FFmpeg-кадр, старый формат и сохранение отсутствующего исходника. Диалоги направлены в тестовые папки.
